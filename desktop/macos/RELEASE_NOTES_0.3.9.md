# freETarget Minimalist 0.3.9-beta.1

- The Connect Target button uses the footer connection status color for connected, connecting, and disconnected states in both light and dark themes.
- The sidebar has square corners.
- The Dashboard control replaces the edge chevron. It shows a four-square icon and label when expanded, and the icon alone when collapsed.
- Removed the Session Controls heading.

Run `bash BUILD_MAC.command` from the extracted source directory to build the application.
