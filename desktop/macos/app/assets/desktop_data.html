Designed for the freETarget Minimalist build. This independent desktop beta is being tested with Minimalist targets. Compatibility with other builds and firmware is unverified.

Desktop Data & Backups

Shooters, guns, History, settings and the custom logo are saved in this app’s local database. App updates use the same data folder.

To migrate: stop the old Python bridge, open the browser exporter in the original browser/profile, download its JSON file, then use Restore / Migrate Data here. Export Backup contains saved data; finish and log an active session first to include its score.

Restore replaces all desktop profiles, records and settings. The browser copy is preserved.
