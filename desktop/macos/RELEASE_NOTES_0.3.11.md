# freETarget Minimalist Desktop 0.3.11-beta.1

- All six widgets support Small and Large. The default is Large. Existing layouts keep their saved sizes.
- An idle shot can open the Start Session dialog. If accepted, the triggering shot is scored when the opening stage accepts shots. During preparation or a timed start it appears as an unscored marker when coordinates are available. Disable the prompt under Settings → General.
- On Mac, pinch the live target to zoom and drag with one finger while zoomed to pan. The zoom percentage resets the view.

Source preview. Native packaging and device checks must be performed on the platform.
